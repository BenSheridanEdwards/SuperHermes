# Skills Layer

Skills are procedural memory. They are how a Hermes profile becomes better over time without bloating bootstrap memory.

## What belongs in a skill

Repeatable workflows, tool-specific commands, known pitfalls, verification steps, user/project quality bars, templates, and references.

## What does not belong in a skill

One-off session outcomes, PR numbers, commit SHAs, secrets, temporary task state, and raw transcripts.

## Skill categories for a strong operator profile

Core: Hermes configuration, memory architecture, profile housekeeping, and verified delivery.

Operator modules: Google Workspace, client email drafting, executive briefings, document/resource publishing, Kanban orchestration, and voice delivery.

Engineering modules: GitHub workflow, debugging, TDD, subagent-driven development, and local CI/CD.

## Maintenance

Load relevant skills before acting. Patch skills immediately when stale or incomplete. Use curator for lifecycle management. Prefer shared skills for fleet-wide patterns and profile-local skills for persona/client-specific patterns.
